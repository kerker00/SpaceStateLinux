# Icons

The tray icons are [Material Design Icons](https://pictogrammers.com/library/mdi/)
(`door-open`, `door-closed`, `help-circle-outline`), licensed under the
Apache License 2.0. Nerd Fonts ship the same set, which the Omarchy bar uses
for its own symbols, so the tray icon matches them.

They are `-symbolic` icons: hosts tint them to the panel's foreground colour.

The application icon in `apps/` is the one of the [SpaceState](https://github.com/kerker00/SpaceState)
apps (MIT), composed from `Shared/AppIcon.icon` without Apple's glass and translucency effects.
